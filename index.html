Code Examples

Get started in minutes with Python or TypeScript. Comprehensive type safety across both languages.

Python
from ahf_ai import TextGenerator, Summarizer, Translator from ahf_ai.safety import ContentFilter # Initialize with responsible defaults generator = TextGenerator( provider="openai", safety=ContentFilter.STRICT, verbose=True # Log each step for learning ) # Generate text with streaming for chunk in generator.stream( prompt="Explain neural networks simply", max_tokens=300 ): print(chunk, end="", flush=True) # Summarize a document summarizer = Summarizer(provider="anthropic") summary = summarizer.summarize( text=long_document, max_length=150, style="bullet_points" ) # Translate with confidence score translator = Translator() result = translator.translate( "Knowledge is power", target="zh" ) print(f"{result.text} ({result.confidence:.0%})")
TypeScript
import { TextGenerator, Summarizer, Translator, ContentFilter } from '@ahf/ai-framework'; // Initialize with responsible defaults const generator = new TextGenerator({ provider: 'openai', safety: ContentFilter.STRICT, verbose: true, }); // Generate text with streaming const stream = generator.stream({ prompt: 'Explain neural networks simply', maxTokens: 300, }); for await (const chunk of stream) { process.stdout.write(chunk); } // Summarize a document const summarizer = new Summarizer({ provider: 'anthropic', }); const summary = await summarizer.summarize({ text: longDocument, maxLength: 150, style: 'bullet_points', }); // Translate with confidence const translator = new Translator(); const result = await translator.translate({ text: 'Knowledge is power', target: 'zh', }); console.log(`${result.text} (${result.confidence})`);
Getting Started

Quick Start

Up and running in under two minutes.

1

Install the package

Available via pip for Python or npm for TypeScript.

pip install ahf-ai
npm install @ahf/ai-framework
2

Set your API key

Configure your preferred provider's API key as an environment variable.

export OPENAI_API_KEY="sk-your-key-here"
3

Write your first query

Import the module and generate text with responsible defaults enabled automatically.

python -c "from ahf_ai import TextGenerator; print(TextGenerator().generate('Hello!'))"
4

Enable verbose mode for learning

Turn on detailed logging to see exactly what happens at each step of the pipeline.

generator = TextGenerator(verbose=True) # See every step explained
Reference

API Reference

Complete documentation for every module and method.

POST TextGenerator.generate()

▼

Generate text from a prompt using the configured AI provider. Applies safety filters by default.

Parameters

promptstrThe input prompt for text generation
max_tokensintMaximum number of tokens to generate (default: 256)
temperaturefloatSampling temperature between 0.0 and 2.0 (default: 0.7)
safetyContentFilterSafety filter level: STRICT, MODERATE, or NONE (default: MODERATE)
streamboolWhether to stream the response token-by-token (default: False)

Returns

responseGenerateResultObject containing .text, .tokens_used, .provider, .safety_flags

POST Summarizer.summarize()

▼

Condense long text into a concise summary. Supports multiple output styles.

Parameters

textstrThe input text to summarize
max_lengthintMaximum word count of the summary (default: 100)
stylestrOutput style: "concise", "detailed", or "bullet_points" (default: "concise")

Returns

summarySummaryResultObject containing .text, .word_count, .compression_ratio

POST Translator.translate()

▼

Translate text between 20+ language pairs with confidence scoring.

Parameters

textstrThe text to translate
sourcestrSource language code, or "auto" for detection (default: "auto")
targetstrTarget language code (e.g., "zh", "es", "fr")

Returns

resultTranslateResultObject containing .text, .source_lang, .target_lang, .confidence

POST Classifier.classify()

▼

Categorize text with confidence scores across custom or predefined label sets.

Parameters

textstrThe text to classify
categorieslist[str]List of category labels to classify against
multi_labelboolAllow multiple labels per input (default: True)
thresholdfloatMinimum confidence threshold for labels (default: 0.1)

Returns

resultClassifyResultObject containing .labels (list of {name, score}), .top_label, .processing_time
Our Mission

Built for the Public Good

The AI Application Framework is part of the Applied Humanity Foundation's mission to advance human well-being through responsible AI application, open-source tools, and digital literacy education.

We believe powerful AI tools should be accessible to everyone -- especially educators, researchers, and nonprofit organizations working to make the world better.

As a 501(c)(3) nonprofit, we develop these tools as public-interest resources. This project does not provide AI models; it provides tools for responsibly using publicly available AI APIs and services.

Our Principles

  • Safety and responsible defaults in every feature
  • Transparency through open source and detailed logging
  • Accessibility for educators and nonprofit developers
  • Privacy-first design with no data collection
  • Community-driven development and governance
